# Gautam Bhawsar Portfolio

A responsive, multipage portfolio built with HTML, CSS and vanilla JavaScript.

## Personalize

- Update social URLs and contact details in the HTML files.
- Add `assets/Gautam-Bhawsar-Resume.pdf` for the download button.
- Replace certificate/project placeholders with real assets and links.
- Update `your-domain.com` in `robots.txt` and `sitemap.xml` before deploying.

Open `index.html` locally or deploy the folder to GitHub Pages, Netlify, or Vercel.
